1. Run `python evidence/ricardo-current-20261108/verify_and_extract.py` from the repository root. It checks every part and complete archive against `MANIFEST.json`.
2. Add `--extract /absolute/path/to/a/new/directory` to reconstruct and safely extract the archives. The original GitHub Actions ZIPs are preserved byte for byte.

Unchanged blobs already in this repository are referenced instead of copied again. The seven unavailable exact objects are listed explicitly. 4. Use the experiment's source revision and its own reproduction instructions. The verifier checks archive integrity, not scientific validity. It does not run archived source code.

## Results and limitations

- **Completed frozen H2/H3 study:** already integrated in [PR #9](https://github.com/AntGalasso/swarmlab/pull/9). Existing evidence is not overwritten.
- **Completed numerical benchmark and observation parity:** already archived in [draft PR #11](https://github.com/AntGalasso/swarmlab/pull/11). The global H-budget hypothesis is unsupported. Original and corrected observation interfaces must remain distinct; cross-platform comparisons are exploratory.
- **GAMMAF voting and detection credit:** already in [PR #12](https://github.com/AntGalasso/swarmlab/pull/12), including Antonio's reproduction. This deposit also preserves later excluded-vote and target-design audits. Retrospective scoring stress tests are not observed online attack success.
- **Crossed observation control:** 17,280 records in the source analysis. Removing the free signal changes the BA and small-world comparisons markedly; star effects are near zero. Preserve the distinction between information access and threshold recalibration.
- **Readiness correction:** 30/30 correct with communication, 2/30 without, 3/30 targeted attacks. The frozen 20% attack criterion failed (`NO_GO`); the larger defense comparison was not launched. The complete original raw Actions artifact is included, with 13,334 ledger calls and 13,333 cached responses.
- **Decision quality / equal signal:** monitor identity assignment matters, but rotation and paid group-warning candidates did not pass their promotion rules. Direct-versus-BAZT and Stop numerical studies retain the shared-sensor and action-set limitations.
- **Stop clean LLM efficiency:** 30 reserved worlds; saved inspections of 16.52% and 36.65% at 1% and 5% intervention caps. Total logical LLM cost falls only 0.203% and 0.526%. Paired answers match in these data. This is clean efficiency evidence, not demonstrated protection under attack or population equivalence.
- **Relay and coordinated-capacity pilots:** admission gates failed and reserved evaluations were not opened. With three corrupted records and only two one-record recoveries, coordinated tasks remain incomplete; quota three restores 8/8 development completions. This is a narrow capacity diagnosis, not a general safety claim.
- **Final-message ablation:** 16 histories from eight development worlds; authentic copy changes 14/16 correct to 15/16, while redaction remains 14/16 and changes which cases fail. Exploratory conditional evidence. The clock-aligned follow-up was blocked by judge HTTP 504 before fresh worlds, not a scientific negative.
- **Newest paired-target experiment:** [run 42487623419](https://github.com/ricardofitas/swarm-adaption-hackathon/actions/runs/42487623419) completed 432/432 debates, with no missing rows or execution errors. However, selected answers are almost all invalid endpoint strings such as `D</ANSWER>`. Both honest-control groups score 0/64; five primary groups score 0/64 and CASPIAN/original 1/64. The frozen secondary parser also does not recover them. Treat this as a completed experiment with a serious output-format/endpoint limitation, not a meaningful demonstrated target effect or defense failure. The complete final artifact, source, plan, traces, ledgers and summaries are preserved.
